# راهنمای صفر تا صد: از صورت‌تمرین تا PDF نهایی

> نسخهٔ راهنما: ۱٫۰ — سازگار با Persian LaTeX Kit v1.2.0 و XeLaTeX در ویندوز
>
> **این فایل را در ریپوی `persian-latex-kit` نگه دار.** مستقل از هر درس است. هر پروژهٔ تکلیف باید در پوشه/ریپوی **جداگانه** ایجاد شود.

## نقشهٔ راه

```
صورت تمرین (PDF/عکس/متن)
      ↓
به‌روزرسانی کتابخانهٔ مرکزی (git pull)
      ↓
ساخت پروژهٔ تکلیف جدید (PowerShell + Git Submodule)
      ↓
تکمیل مشخصات درس و دانشجو
      ↓
هر سؤال در یک فایل جدا + منابع/شکل‌ها در assets/
      ↓
XeLaTeX → PDF → بازبینی اعداد، علائم، راست‌به‌چپ، فرمول و جدول
      ↓
ثبت نسخه در Git → تحویل طبق دستور استاد
```

## ۰. پیش‌نیازها — فقط یک بار

- TeX Live، TeXstudio و Git for Windows نصب باشند.
- در TeXstudio گزینهٔ `Options → Configure TeXstudio → Build → Default Compiler` روی **XeLaTeX** باشد.
- فونت **B Nazanin** در Windows Fonts نصب باشد. فونت در ریپو نگهداری نمی‌شود. کتابخانه اگر فونت پیدا نشود به Amiri برمی‌گردد؛ باید آن فونت هم در سیستم موجود باشد.
- برای کار با ریپوی خصوصی، Git باید دسترسی معتبر GitHub داشته باشد.
- مسیر پوشه‌ها را ترجیحاً با حروف انگلیسی انتخاب کن؛ مثلاً `E:\uni\assignments`.

بررسی سریع در PowerShell:

```powershell
git --version
xelatex --version
```

## ۱. هر بار قبل از ساخت تکلیف: کتابخانه را تازه کن

```powershell
cd "E:\uni\Persian_LaTeX_Kit_Git_Ready_v1.1.0\persian-latex-kit"
git pull --ff-only origin main
```

> **مسیر بالا صرفاً مسیر فعلی نمونه است**؛ اگر کتابخانه را جابه‌جا کردی، آن را متناسب با سیستم خودت عوض کن. بهتر است پوشهٔ Git را به یک مسیر پایدار مثل `E:\uni\persian-latex-kit` منتقل کنی؛ این تغییر Git را خراب نمی‌کند.

## ۲. یک پروژهٔ جدید برای هر تکلیف ایجاد کن

از داخل پوشهٔ کتابخانه:

```powershell
.\scripts\new-assignment.ps1 -Destination "E:\uni\assignments\simulation-hw1" -RepositoryUrl "https://github.com/goodguy-not/persian-latex-kit.git"
```

اگر PowerShell جلوی اجرای اسکریپت را گرفت، **بدون تغییر دائمی تنظیمات سیستم** در همان پنجره اجرا کن:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

سپس فرمان ساخت تکلیف را دوباره اجرا کن. این فرمان `git init` و `git submodule add` را اجرا می‌کند؛ به اینترنت و دسترسی به GitHub نیاز دارد. مقصد **نباید از قبل وجود داشته باشد**؛ اگر خطایی رخ داد، پیش از تکرار، وضعیت پوشهٔ نیمه‌ساخته را بررسی کن و داده‌های شخصی‌ات را پاک نکن.

پوشهٔ تازه تقریباً به این شکل است:

```
simulation-hw1/
├── main.tex
├── AGENTS.md                    ← دستورهای مخصوص دستیارهای هوش مصنوعی
├── config/metadata.tex          ← مشخصات این تمرین
├── questions/question01.tex     ← جواب سؤال اول
├── assets/                     ← شکل‌های قلم/تبلت، PDF و PNG
└── vendor/persian-latex-kit/   ← نسخهٔ قفل‌شدهٔ کتابخانه (Submodule)
```

## ۳. مشخصات را وارد کن

فایل `config/metadata.tex` را باز کن و فقط مقدار این موارد را عوض کن:

- `\HWStudentName`، `\HWStudentID`
- `\HWCourse`، `\HWProfessor`، `\HWTerm`
- `\HWAssignment`، `\HWInstitution`، `\HWDeadline`

اطلاعات شخصی یا متن تکلیف را داخل **ریپوی عمومیِ کتابخانه** نگذار. فقط داخل پروژهٔ تکلیف ثبت کن (در صورت نیاز، ریپوی خصوصی).

## ۴. متن سؤال‌ها و شکل‌ها

- فایل `questions/question01.tex` را با یک `\HWQuestion` شروع کن.
- برای قسمت‌ها از `\HWPart{الف}`، `\HWPart{ب}`، ... استفاده کن.
- برای اصطلاح انگلیسی در متن فارسی: `\Term{موجودیت}{Entity}` یا `\EN{FIFO}`. از نوشتن مستقیم `(` و `)` دور کلمهٔ لاتین پرهیز کن؛ دستورهای کتابخانه جهت و فاصله را مدیریت می‌کنند.
- برای فرمول از `\[ ... \]` و برای جدول رنگی از `HWTable` استفاده کن (نمونه‌ها در `examples/snippets/`).
- تصویر یا شکل تبلت را در `assets/` بگذار و با `\HWFigure[0.7]{assets/figure1.png}{توضیح شکل}` درج کن.
- فایل `questions/question02.tex` و ... را بساز و در `main.tex` با `\input{questions/question02}` وارد کن. **قالب، رنگ و فونت را در فایل سؤال بازتعریف نکن.**

## ۵. ساخت PDF و کنترل کیفیت

در TeXstudio **همیشه `main.tex`** را باز کن (نه `question01.tex`) و XeLaTeX را اجرا کن. روش خط فرمان از ریشهٔ پروژه:

```powershell
cd "E:\uni\assignments\simulation-hw1"
xelatex -interaction=nonstopmode -halt-on-error main.tex
```

چک‌لیست خروجی PDF:

- [ ] B Nazanin واقعاً نمایش داده می‌شود؛ اگر نه، نصب فونت و شناخته شدن آن را بررسی کن.
- [ ] پاراگراف‌ها راست‌به‌چپ و متن‌ها راست‌چین هستند.
- [ ] پرانتز اصطلاح‌های انگلیسی برعکس یا جدا نیفتاده‌اند.
- [ ] شمارهٔ سؤال، شمارهٔ صفحه و اعداد متن مناسب و خوانا هستند.
- [ ] جدول و فرمول بیرون حاشیه نرفته و هیچ خطی بریده نشده.
- [ ] خروجی شامل همهٔ بخش‌های خواسته‌شدهٔ صورت سؤال و مراحل لازم است.
- [ ] نام فایل و فرمت تحویل دقیقاً مطابق درخواست درس است.

اگر PDF دو بار کامپایل لازم داشت، مجدداً XeLaTeX را اجرا کن. فایل‌های `.aux`، `.log` و مشابه را لازم نیست Commit کنی؛ `.gitignore` آن‌ها را کنار می‌گذارد.

## ۶. کار با هوش مصنوعی — متن آمادهٔ قابل کپی

**این دستور را در یک گفت‌وگوی جدید به هوش مصنوعی بده؛** بهتر است صورت تمرین را هم فایل پیوست کنی. اطلاعات داخل `[کروشه]` را برای هر تمرین جایگزین کن:

```text
در حال نوشتن تکلیف درس [نام درس] در پروژه LaTeX هستم. از کتابخانهٔ شخصی
https://github.com/goodguy-not/persian-latex-kit
استفاده می‌کنم (نسخهٔ فعلی پروژه در vendor/persian-latex-kit قرار دارد).

ابتدا فایل‌های AGENTS.md پروژه، main.tex، config/metadata.tex و
vendor/persian-latex-kit/tex/persian-kit.sty و مستندات docs/COMPONENTS_FA.md
کتابخانه را بخوان؛ اگر دسترسی به ریپو یا فایل‌ها نداری، صریح بگو و از من
بخواه فایل ZIP پروژه یا فایل‌های لازم را پیوست کنم. بر اساس حدس، دستور
LaTeX جدید اختراع نکن.

قواعد کار:
۱) با XeLaTeX و XePersian کار کن؛ متن فارسی راست‌به‌چپ، فونت ترجیحی
B Nazanin و اعداد فارسی باشد.
۲) همهٔ سؤال‌ها در questions/questionXX.tex قرار گیرند و از main.tex
با input فراخوانی شوند. اطلاعات تکلیف فقط در config/metadata.tex باشد.
۳) از ماکروهای موجود مثل HWQuestion، HWPart، Term، EN، HWTable، HWFigure
و HWTip استفاده کن؛ فونت و رنگ را داخل فایل سؤال تکرار نکن.
۴) اصطلاح انگلیسی را با EN یا Term داخل متن فارسی وارد کن. جهت پرانتزها،
علائم نگارشی فارسی و صفحه‌بندی را هنگام تولید PDF کنترل کن.
۵) قبل از نوشتن، خواسته‌های دقیق صورت سؤال را استخراج کن؛ مراحل محاسبات
مهم را حذف نکن. موارد نامشخص را مشخص کن و حدس نزن.
۶) اگر کامپوننت جدیدی لازم است، اول توضیح بده چه چیزی کم است؛ سپس تغییر
آن را برای ریپوی اصلی کتابخانه در قالب فایل مجزا پیشنهاد بده، به جای دستکاری
vendor/ در پروژهٔ تکلیف.
۷) خروجی هر مرحله را ترجیحاً به شکل فایل .tex قابل استفاده، همراه با
مسیر دقیق قرارگیری، و در صورت امکان PDF بررسی‌شده بده.
۸) چیزی از فایل‌های شخصی من را وارد ریپوی عمومی کتابخانه نکن.

کار فعلی: [مثلاً حل سؤال ۱، قسمت‌های الف تا د، از فایل صورت تمرین پیوست]
```

**نکتهٔ دسترسی:** ارائهٔ لینک GitHub به‌تنهایی به معنی توانایی خواندن ریپوی خصوصی یا فایل‌های لپ‌تاپ توسط هر مدل هوش مصنوعی نیست. در صورت نیاز پروژه یا حداقل فایل‌های بالا را بارگذاری کن، یا دسترسی GitHub را با اجازهٔ خودت متصل کن.

## ۷. ذخیرهٔ پروژه و تحویل

پروژهٔ تمرین خودش یک ریپوی مستقل محلی دارد. در ریشهٔ پروژه:

```powershell
git status
git add .
git commit -m "Complete simulation homework 1"
```

اگر بخواهی تمرین هم در GitHub باشد، **یک ریپوی خصوصیِ مجزا** برای تمرین بساز؛ سپس (به جای نام واقعی و آدرس واقعی، از نام مناسب استفاده کن):

```powershell
git remote add origin https://github.com/YOUR_USERNAME/YOUR_PRIVATE_ASSIGNMENT_REPO.git
git push -u origin main
```

ریپوی کتابخانه فقط ابزارها و ظاهر را نگه می‌دارد، نه پاسخ تمرین‌ها. PDF نهایی را مطابق سامانهٔ تحویل استاد ارائه کن.

## ۸. افزودن یک کامپوننت جدید و استفادهٔ مجدد

مثلاً وقتی «کدبلاک رنگی» لازم شد:

۱. در **ریپوی اصلی کتابخانه**، یک ماکرو/محیط مناسب در `tex/` یا بخش مستقل مرتبط بساز.
۲. فایل نمایش نمونه در `examples/snippets/` و توضیح نحوهٔ استفاده در `docs/COMPONENTS_FA.md` اضافه کن.
۳. `gallery.tex` و نمونه‌ها را با XeLaTeX تست کن؛ خروجی را بصری بررسی کن.
۴. در `CHANGELOG.md` ثبت کن؛ سپس در **پوشهٔ کتابخانه**:

```powershell
git add .
git commit -m "Add reusable code block component"
git push origin main
```

۵. اگر خواستی تمرین فعلی هم به نسخهٔ جدید کتابخانه مهاجرت کند، از داخل **پوشهٔ پروژهٔ تمرین**:

```powershell
git -C vendor/persian-latex-kit pull --ff-only origin main
git add vendor/persian-latex-kit
git commit -m "Update shared LaTeX kit"
```

> این به‌روزرسانی **اختیاری** است: هر پروژه تا زمان تصمیم خودت به نسخهٔ قبلی کتابخانه متصل می‌ماند. بعد از آپدیت، PDF قبلی را دوباره کامپایل و بازبینی کن.

## ۹. رفع خطاهای رایج

| علامت خطا | دلیل محتمل | اقدام |
|---|---|---|
| `xelatex not recognized` | TeX Live در PATH نیست | ترمینال جدید باز کن؛ نصب و PATH را بررسی کن. |
| `persian-kit.sty not found` | Submodule دانلود نشده یا از پوشهٔ اشتباه کامپایل می‌کنی | از ریشهٔ پروژه اجرا کن؛ `git submodule update --init --recursive` را بزن. |
| `font "B Nazanin" cannot be found` یا فونت تغییر می‌کند | فونت نصب یا شناسایی نشده | فونت را در Windows Fonts نصب و TeXstudio را دوباره باز کن. |
| شماره‌ها یا پرانتزها جابه‌جاست | متن لاتین مستقیم در محیط فارسی نوشته شده | از `\EN{}` و `\Term{}{}` استفاده کن، سپس PDF را بررسی کن. |
| `Destination already exists` | مسیر پروژه از قبل ساخته شده | مسیر جدید انتخاب کن؛ اطلاعات قبلی را بدون بررسی پاک نکن. |
| `git submodule add failed` | شبکه/دسترسی GitHub یا ریپو | `git ls-remote https://github.com/goodguy-not/persian-latex-kit.git` را تست کن. |
| تغییرات کتابخانه در تمرین اعمال نمی‌شوند | Submodule روی یک Commit قدیمی قفل شده | مراحل بخش ۸ را برای آپدیت اختیاری انجام بده. |
