# English ModernCV project guidance

Begin with `AI_START_HERE.md` and `AI_MACROS.md` in this generated project.

Keep the ModernCV class and restrained Classic style unless the document has a
real formatting requirement. Preserve TeX Gyre Heros as the default font.
Edit `config/metadata.tex` and section files, not the styling implementation,
for candidate content. Repeat `\cventry` and `\cvitem` freely. Omit optional
section inputs in `main.tex` when unused; use `\CVSection` for new sections.
Do not add real personal information or font binaries to the reusable toolkit.
Compile with XeLaTeX from this project root and inspect each PDF page.
