# پروژهٔ تک‌سؤال با ظاهر تاریخی OS

این قالب **یک سؤال در هر PDF** می‌سازد؛ سربرگ، پابرگ، جدول دو نفر و
سبک پاسخ از `vendor/persian-latex-kit/tex/persian-os.sty` می‌آیند.
مولد به‌صورت پیش‌فرض یک نسخهٔ مستقل و ثابت می‌سازد و Git لازم ندارد.

1. `config/metadata.tex` را با مشخصات همان پروژه و شمارهٔ سؤال پر کنید.
   `config/fonts.tex` برای تغییر اختیاری فونت است؛ پیش‌فرض Vazirmatn.
2. پاسخ را فقط در فایل `questions/questionNN.tex` که `main.tex`
   وارد می‌کند بنویسید. برای سؤال بعدی پروژهٔ جدید بسازید.
3. از ریشهٔ پروژه `main.tex` را در TeXstudio با XeLaTeX یا با
   `latexmk -xelatex -outdir=build main.tex` کامپایل کنید.
4. PDF را برای جهت متن، علائم، جدول، کد، سربرگ و پابرگ بازبینی کنید.

## قطعات پاسخ

- `\OSPart{آ}[عنوان]`: تیتر بخش؛ `\OSLatin{fork()}`: نام فنی لاتین.
- `\OSParen{متن}` و `\OSBracketed{متن}`: نشانه‌های دور متن فارسی؛
  `\OSDateRange{۱۴۰۵}{۱۴۰۶}`: بازهٔ تاریخ.
- `\begin{latin}\begin{lstlisting}[style=OSCode] ...`: کد C چپ‌به‌راست
  با شمارهٔ خط؛ هر دو محیط را ببندید.
- `\OSFigure[0.75]{assets/example.png}{عنوان}`، `tabularx`، و محیط‌های
  ریاضی برای شکل، جدول و فرمول در دسترس‌اند.

در نثر فارسی از `، ؛ ؟ « »` استفاده کنید. نشانه‌های ASCII پرانتز/کروشه
را مستقیم دور متن فارسی نگذارید. فایل‌های فونت در مخزن اصلی توزیع نمی‌شوند.
گزینهٔ قدیمیِ فونت محلی Vazirmatn با `\OSVazirmatnPath` در
`config/fonts.tex` همچنان موجود است؛ آن را با `\PLKPersianFont` ترکیب
نکنید. راهنمای کامل در `docs/OS_SINGLE_QUESTION_FA.md` مخزن اصلی است.

ظاهر این قالب از یک سند Word تاریخی الهام گرفته است؛ برابری دقیق پیکسل‌ها
بین Word و TeX تضمین نمی‌شود. پیش از استفادهٔ نهایی، PDF را با نیاز واقعی
سند خود مقایسه کنید.
