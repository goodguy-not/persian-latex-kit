# English letter project guidance

The class is fixed when this project is generated: standard `letter` for Classic
or KOMA-Script `scrlttr2` for Modern. Preserve that class and the approved
Termes/Heros font defaults unless a document requirement justifies a change.
Edit metadata, font configuration and content in this project. Keep the last
paragraph in `content/final-paragraph.tex` with the closing and signature.
Optional sender organization and phone can remain empty. Compile with XeLaTeX
and inspect page breaks, visual hierarchy, and embedded fonts.
