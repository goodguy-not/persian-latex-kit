# Persian letter project guidance

Edit only this generated project's metadata, font configuration, content and
sender-owned assets. Preserve the selected article/XePersian presentation and
Vazirmatn default unless the document requirements justify a change. Keep
ordinary paragraphs in `content/body.tex` and the last paragraph in
`content/final-paragraph.tex` so closing and signature stay together. Optional
organization, logo, letter number, attachment, and opening phrase may remain
empty. Do not place a recipient logo in the sender header. Compile with XeLaTeX
and inspect RTL, punctuation, page breaks, and embedded fonts.
